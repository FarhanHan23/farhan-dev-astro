folder pages untuk routing di astro js

tinggal bikin folder baru dalam folder pages, misal folder posts, terus bikin file baru di dalamnya, misal artikel-1.md
nanti tinggal akses di browser dengan url localhost:3000/posts/artikel-1

setiap mau menulis script di astro js, tinggal bikin file baru dengan ekstensi .astro, misal Header.astro, terus tulis scriptnya di dalamnya, nanti tinggal import di file index.astro
pakai tandai strip 3 --- nah di dalamnya baru tulis logic scriptnya, misal import component lain, atau bikin variable baru, dll
